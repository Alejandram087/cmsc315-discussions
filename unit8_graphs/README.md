# Unit 8 Discussion: Breadth-First Search (BFS)

## Overview

This assignment explores graph traversal using Breadth-First Search (BFS).

## Learning Objectives

- Represent graphs using adjacency lists
- Implement BFS
- Use queues in graph traversal
- Analyze graph traversal behavior

## Requirements

1. Create a graph.
2. Perform BFS traversal.
3. Add nodes or edges.
4. Demonstrate edge cases.
5. Analyze BFS behavior.
6. Create a real-world graph example.


## Discussion Board Reflection

While completing this assignment, I learned how graphs can be represented using adjacency lists and how Breadth-First Search (BFS) works to visit connected nodes. I learned that BFS uses a queue to process nodes in the order they are discovered and a visited set to prevent the same node from being processed more than once. I also practiced adding nodes and connections and testing different edge cases.

One challenge I encountered was understanding when a node should be added to the queue and marked as visited. Following the traversal step by step and looking at the program output helped me understand how BFS moves through the graph. Testing a missing starting node and a graph with only one node also helped me see why handling edge cases is important.

BFS and Depth-First Search (DFS) traverse graphs differently. BFS explores nearby nodes level by level, while DFS follows one path as far as possible before backtracking. BFS is useful for navigation, social networks, and finding paths with fewer connections. DFS can be useful for exploring file directories, dependency structures, and other problems that require deeper exploration.
